# 国企汇报文风 · State-owned Enterprise Report Style

把汇报材料改成"实事求是、务实、专业"的体制内文风——摆事实、给数字、下判断、敢写问题。类似毛选、邓选的行文气质，去掉"飘、空、幼稚、业余、太官话"的表达。

A Claude Code skill that rewrites SOE / institutional report materials into a pragmatic, fact-based style — facts and numbers over adjectives and slogans.

---

## 核心原则 · Core Principles

| 原则 Principle | 说明 Description |
|------|------|
| 用事实和数字说话 | 形容词和情绪 → 数字、对象、结果 / adjectives → facts, numbers, outcomes |
| 主语具体、动词落地 | 谁 + 做了什么 + 做到什么程度 / concrete subject + verb + object |
| 短句、一句一义 | 砍长定语和排比堆砌 / short sentences, one idea each |
| 成绩说够、问题说透 | 实事求是，敢写不足 / report problems honestly |
| 结论先行 | 每段先给判断，再摆事实 / conclusion first, evidence after |
| 用词朴素克制 | 避开"赋能、抓手、闭环"等空词 / avoid empty jargon |

## 用法 · Usage

- **自动触发 Auto**：把草稿贴给 Claude，说"按务实文风改""这材料太飘了，压一压"
- **显式触发 Explicit**：`/tiantan-report-style`
- **配合使用**：与 [`tiantan-general-word-format`](https://github.com/pescadosalado/tiantan-general-word-format) 配合——一个管文风，一个管格式

## 结构模板 · Standard Structure

```
一、基本情况 / 工作完成情况   → 成绩，用数据说话
二、主要做法与举措           → 怎么做的，落在具体动作
三、存在的问题与不足         → 敢写，实事求是，不回避
四、下一步工作思路与计划     → 有针对性的措施，别空喊口号
```
